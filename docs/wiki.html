copilot-agents Documentation

Provider terminology and ownership boundaries.

research-agents

The explicit Ploinky deployment bundle for the provider suite. Operators select it independently of Explorer startup. Its declared profiles enable the relay and four no-wait provider children, including AchillesCLI-owned GPTResearcher. The bundle owns deployment metadata; each provider owns task execution. A successful bundle launch does not certify every provider task path.

copilotProviderRelay

The authenticated MCP broker for provider tasks. A caller supplies a backend id, prompt and bounded resources; the relay requires a Router invocation token, validates paths and size limits, calls the declared provider tool, and normalizes its result. It does not own model configuration, browser profiles or sandbox command setup. Task submission, backend listing and status are separate tools.

Provider backend

A catalog record pairing a public backend id with one agent and MCP tool. The active ids are open-interpreter, web-search and browser-use. The relay uses the record to forward tasks without embedding backend command strings. Reserved names have no callable provider until an agent and contract are registered; listing a backend does not prove runtime readiness.

openInterpreterAgent

The provider that owns Open Interpreter setup, bounded resource staging and execution policy. Its maintained shared runner image is pinned by digest, while its retained privilege declaration has a separate certification gate. Generated-local Box signals cause PLOINKY_OPEN_INTERPRETER_BOX_UNAVAILABLE before preparation; operator endpoint settings cannot bypass that refusal. A transport image check does not certify provider execution.

webSearchAgent

The provider for web-search tasks through a local headless browser service. It returns an answer with citations and advertises cacheability with a TTL hint of 86400 seconds. The consuming application owns actual cache lookup and storage. Browser runtime failures must yield unavailable output rather than invented evidence. Private cache and browser state belong to the provider data root.

browserUseAgent

The interactive browser provider for registered web application adapters. It owns persistent Chromium profiles and returns protected viewer links when login or another human action is required. Session reuse is scoped to the authenticated user and selected provider. Tasks can be continued through the provider tools; results are interactive and non-cacheable. Cookies stay in provider-private storage.

AgentMcpClient

Ploinky's authenticated agent-to-agent client. It verifies the runtime-owned Router descriptor before credential or socket use, presents the signed request authority, signs the agent assertion and forwards the current invocation token as user delegation. Provider launchers and the relay reuse it rather than constructing raw Router requests. It does not make an unavailable provider executable.

Router

Ploinky's authenticated entry point for agent HTTP and MCP calls. The runtime owns its listener origin, request authority and active routing generation. Consumers use the verified descriptor and delegated invocation token, keeping direct agent ports and reusable credentials outside caller-controlled inputs. Optional provider names and prompt interpretation belong to consuming agents.

Shared runner image

The digest-pinned container image used by provider-owned sandboxes and supported sibling consumers. Bubblewrap confinement runs inside the provider container; research-agents does not enable a separate basic/bwrap-runner agent. Image transport and installation checks establish only their named contracts. Open Interpreter still requires private-proc and provider certification before privilege removal.

GPTResearcher

The optional research worker owned by the legacy-agents repository (Ploinky ref legacy-agents/GPTResearcher, formerly AchillesCLI/GPTResearcher). The bundle enables it as a no-wait child while its own manifest uses manual startup. It writes Markdown reports with web and optional local evidence through its declared model and search adapters. Generated-local model access has a fail-closed certification boundary. Its complete contracts belong to legacy-agents/GPTResearcher/docs, not a nonexistent local DS015 research specification.
